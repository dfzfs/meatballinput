# 🎬 미트볼 지시창

채팅에 안 남는 지시를 넣는 창이에요. 입력창 왼쪽 🎬 버튼으로 열어요.
**미트볼 상태창 3**과 같이 쓰면 비밀 · 방향 · 내 지침까지 다 쓸 수 있어요. 없으면 「지시」와 「이름」만 돼요.

## 설치
- 미트볼 상태창 3 설정의 **「🎬 지시창 받기」** 버튼을 누르거나
- 실리태번 › 확장 › **Install extension**에 이 주소:
  ```
  https://github.com/dfzfs/meatballinput
  ```
설치하고 새로 고치면 입력창 왼쪽에 🎬가 생겨요.

## 탭
- **지시**: 그냥 적으면 다음 답 한 번. 📌 이 장면 동안 · 📌 계속
- **비밀**: AI가 먼저 말하면 안 되는 것. 본편 AI에는 안 가고 미트볼만 지켜요. 「보여도 되는 모습」만 AI에게 가요
- **방향**: 이야기가 결국 갈 곳. AI는 몰라요. 너무 빨리 가면 ⚠. 「살짝 알리기」는 "천천히"만 전달
- **이름**: 보내는 글에서만 {{char}} · {{user}} 이름을 잠깐 바꿔요. 캐릭터 · 채팅은 안 바뀌어요
  - 퀵리플: `/mbname char=깡통 user=깡캐 also=다른이름` 다음에 `/gen …`
  - 바뀐 곳 수가 알림으로 떠요. 0곳이면 경고
- **규칙**: 지킬 것을 한 줄로 적어요. 미트볼이 답을 정리할 때 같이 훑어보고, 어긴 게 있으면 다음 답 하나에만 주의를 붙이고 꺼져요
  - 보이면 주의 / 항상 / 끔
  - 기본 지침 8개(유아화 · 무시 · 소유 선언 금지 등)도 켜고 끌 수 있어요

PC에서는 제목줄 ⇤ ⇥로 채팅 옆에 붙일 수 있어요. 탭 설명은 제목줄 ?에 있어요(폰은 눌러서).

## 알아 둘 점
- 정리가 끝나기 전에 다음 글을 보내면 그 턴은 지침 판정이 빠져요. 상태창 3 설정 「분류 중에 보내면 끝날 때까지 기다렸다 보내기」를 켜면 괜찮아요.
- 이름 바꾸기는 `/genraw`에서는 안 먹을 수 있어요.
